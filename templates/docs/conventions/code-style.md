# 코드·문서 공통 작성 규칙

> 전역 적용. 스택별 세부는 {{STACK_DOC_LINKS}}.

## 언어

- **산출물 문서·코드 주석은 한국어**(constitution ①). 커밋 제목도 한국어.
- 영문으로 쓰는 것: 파일·폴더 이름 · 브랜치명 · PR 제목 · 코드 식별자(변수·함수·타입).

## 이름

- **파일·폴더 이름은 영문 kebab-case**. 한글 파일명은 `git ls-files` 의 인용 처리·훅의 경로 패턴 매칭에서 조용히 어긋나 전수 검색과 pre-commit에서 함께 빠진다.
- 순서가 중요한 문서 묶음은 숫자 접두를 붙인다 (`01-...`).

## 문서

- 새 규약·컨벤션 문서는 `docs/conventions/` 에만 만들고 **같은 커밋에서** [INDEX.md](INDEX.md) 에 등재한다 — 그 밖의 위치는 PreToolUse 가드와 pre-commit이 차단한다.
- 리포에 커밋되는 문서에 **리포 밖 경로**(절대경로 · 상위로 이탈하는 상대경로)를 적지 않는다. 경로는 리포 루트 기준으로 쓴다.
- 허브 `CLAUDE.md` 와 `.claude/rules/*` 는 **200줄 이하**를 목표로 한다. 넘치면 `paths` 범위 규칙이나 스킬로 분리한다.

## 인코딩·개행

- `.editorconfig` 가 정본이다: UTF-8 · LF · {{INDENT_SUMMARY}} · 파일 끝 개행.
- 소스 편집 직후 PostToolUse 훅이 린터 자동수정을 실행한다 — 수동 정렬로 다투지 않는다.

## 주석

- **"무엇을"이 아니라 "왜"**를 적는다. 무엇을 하는지는 코드가 말한다.
- 구역 주석은 `{{SECTION_COMMENT}}` 형태로 통일한다.
