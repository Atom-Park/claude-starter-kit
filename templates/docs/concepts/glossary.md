# 용어 사전 — {{REPO}}

> 이 리포에서 쓰는 용어의 정의. 킷이 만드는 공통 구조·장치 용어(전 리포 동일)와 **이 리포 고유 대상**(모듈·패키지·경계)을 담는다 — 킷 층은 평시 참조 대상이 아니므로 여기서 가리키지 않는다.

| 용어 | 의미 |
|---|---|
| 허브 | 리포 유일 진입점 `CLAUDE.md`. 전 자산 링크의 시작점 |
| 승격 | 개인층(로컬 gitignore 영역) 산출물을 검토·채택해 리포층(커밋)으로 올리는 것 |
| constitution | 리포 원칙 3~5개 — 시작 시 1회 확정, 게이트(훅·PR 리뷰)로 강제 (`docs/constitution.md`) |
| 컨벤션 인덱스 | `docs/conventions/INDEX.md` — 모든 컨벤션 문서의 단일 참조점 |
| 수정 경계 | 이 리포에서 Claude 작업이 수정할 수 있는 영역 — 값은 허브 상단이 정본 |
| MEMBER-BOOTSTRAP | 팀원용 개인 셋팅 실행 문서(리포 루트) — 팀원의 유일한 실행 문서 |
| .claude/rules | Claude **자동 주입** 규칙(주제당 1파일, `paths`로 경로 범위 지정) — 정본 컨벤션의 집행 요약 |
| .claude/skills | 절차층 — 여러 단계로 반복 실행되는 절차(변경 전파·커밋/PR). **호출할 때만** 로드된다 |
| 지도표 | 자주 바뀌는 사실이 어느 문서 어디에 적혀 있는지의 위치 지도 — 셋팅 변경 시 전파 스킬이 읽는다 |
| 킷 층 | `.claude-starter-kit/` — **변경 지도표를 두는 자리**. 평소 개발에서 열 일은 없다(셋팅을 바꿀 때 전파 스킬이 읽는다) |
| 보호 경로 | 공통 참조 문서에 거는 ask 권한 규칙 — 인터랙티브 모드에서 수정 전 확인 강제. 무인·자동 승인 모드는 자동 승인되므로 가드가 감사 기록을 남기고 사후 보고 훅이 알린다 |
| plan 모드 | 편집 없이 계획을 세워 승인받은 뒤 실행하는 권한 모드 — 규모 변경 선행 권장 |
